Claude YouTube Connector

A private helper that lets the channel owner's Claude assistant manage the owner's own YouTube channel: uploading the owner's videos with titles, descriptions, tags and thumbnails, scheduling them, organising playlists, replying to comments and reading channel analytics.

How it works

  • On the owner's PC: a local connector inside the Claude desktop app talks to the YouTube Data API and YouTube Analytics API using the owner's own Google sign-in.
  • When the PC is off: finished videos placed in the owner's Google Drive folder "Claude YouTube Queue" are uploaded by a GitHub Actions job in this repository, and the Drive copies are deleted afterwards to free space.
  • It is used only for the owner's own channel and is not offered to other users.
