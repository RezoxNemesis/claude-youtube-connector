Privacy policy

Claude YouTube Connector · last updated 15 November 2026

Claude YouTube Connector ("the tool") is a personal tool used only by the owner of one YouTube channel to manage that channel with the help of the owner's Claude assistant. It is not offered to the public.

YouTube API Services

The tool uses YouTube API Services. Using it means you agree to the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

What the tool accesses

  • YouTube account data (through the YouTube Data API): channel details, the owner's videos, playlists and comments, so it can upload videos, edit their titles, descriptions, tags, thumbnails and schedules, manage playlists and reply to comments.
  • YouTube Analytics (read-only): view, watch-time and audience reports for the owner's channel.
  • Google Drive: only to read videos, thumbnails and upload instructions the owner places in the folder "Claude YouTube Queue", and to delete those files after they are uploaded.

How data is used, stored and shared

  • Data is used only to carry out the owner's own requests on the owner's own channel.
  • The Google sign-in token is stored on the owner's computer (in a file only the owner can read) and, for uploads while the computer is off, as an encrypted GitHub Actions secret in the owner's repository.
  • Video files pass straight from the owner's computer or Google Drive to YouTube; the tool keeps no copies. Drive copies are deleted after a successful upload.
  • The tool does not sell, rent or share any data with third parties and shows no ads. When the owner asks Claude to act on the channel, the request and results pass through the owner's own Claude account.
  • No cookies or tracking are used by this tool or these pages.

Deleting data and revoking access

  • Revoke the tool's access at any time from your Google Account: security.google.com/settings/security/permissions.
  • Deleting the folder ~/.config/claude-youtube on the computer and the YT_CLOUD_KEY secret in the GitHub repository removes every stored token.
  • Data obtained from YouTube is not stored by the tool beyond the current request, so there is nothing further to delete.
